## 应用目标

整理者推导：把记账系统从金额记录升级为自由时间记录，让收入、消费、资产和自由天数能互相换算。

## 系统字段

| 字段 | 用法 |
|---|---|
| 可支配资金 | 计算当前自由天数 |
| 日均花销 | 决定资产可支撑时长 |
| 单笔消费 | 换算消耗的自由天数 |
| 收入记录 | 换算新增自由天数 |
| 支出类型 | 区分日常消费、必要支出、生产资料 |
| 自由天数 | 用于月度复盘和长期目标 |

## 当前可执行改法

- [ ] 导出现有记账数据。
- [ ] 计算当前日均花销。
- [ ] 计算现有可支配资金对应的自由天数。
- [ ] 给最近 10 笔大额消费补充自由天数消耗。
- [ ] 月复盘时增加自由天数变化。

## 验证方式

| 指标 | 判断方式 |
|---|---|
| 决策影响 | 是否减少冲动消费 |
| 感知提升 | 是否更直观看到财务安全垫 |
| 数据成本 | 记录成本是否可持续 |
| 长期价值 | 是否帮助设定副业收入目标 |
