# 星火杯选题与作品设计

## 选题边界

只选择大学生学习、生活或就业中的一个高频真实问题。作品需要基于星辰 Agent 平台，且能展示从理解问题到执行动作的完整闭环。

## 当前切入口

参考项目：财富自由指南灯  
仓库：<https://github.com/qxiu539/wealth-freedom-lighthouse>

现有工具把净储蓄按平均日花销换算为自由天数，再通过人生方格图显示。它适合承担数据输入、计算和结果呈现。

参赛作品将以智能体为主体。智能体需要在现有可视化之外完成多步理解、判断、行动建议和后续反馈。现阶段已确认升级为证据型大额消费决策智能体。正式设计见 [证据型大额消费决策智能体设计](../docs/superpowers/specs/2026-07-30-evidence-based-purchase-decision-agent-design.md)。

## 已确认的智能体方向

介入时机：消费前。

初步任务：当大学生准备购买某件商品或服务时，智能体理解购买意图，读取用户的收支、平均日花销和财富目标，把价格换算成自由天数，并帮助用户做出更清楚的消费决定。

初步执行闭环：表达购买意图 → 补充必要信息 → 调用财务数据 → 计算自由天数影响 → 给出决策建议 → 记录最终选择 → 后续反馈。

首版聚焦：单价较高或容易冲动购买的消费，包括数码产品、付费课程、旅行和游戏充值。普通餐饮、交通等高频小额支出暂不作为首版主场景。

## 最小验证要求

每个候选问题至少收集 3 位目标用户的具体描述，避免只按个人猜测开发。验证时记录问题出现的频率、目前替代方案、最困扰的一步，以及用户是否愿意实际使用。

## 最终作品方案

作品名称：财富自由指南灯。

一句话价值：把大额消费的财务影响、真实需求证据和替代方案放在一起，帮助大学生形成可追溯的消费决定。

目标用户：需要自主决定数码产品、课程、旅行等单笔较大消费的大学生。

核心痛点：用户能看到价格，但难以同时判断现金安全垫、需求是否充分和替代方案的实际代价。

输入：购买内容、价格、可支配资金、平均日花销、记账天数、当前问题、影响频率、购买期限、预期使用频率和替代方案。

智能体的判断与工作流：先执行确定性财务计算，再判断需求证据和替代证据，最终输出独立于财务灯号的决策状态。

工具或知识库：星辰工作流、确定性公式节点、决策规则、隐私与安全边界说明。

输出与执行结果：自由时间影响、需求证据、替代方案比较、财务灯号、决策状态、一个当天行动和复盘入口。

验证指标：三位大学生能在两分钟内完成分析，理解自由天数，说出一条事实依据并执行一个下一步动作。

作品链接：待发布。

## 开发检查

- [ ] 用户能在首次使用时理解用途和输入方式。
- [ ] 智能体能给出可执行结果，结果不只停留在泛泛建议。
- [ ] 工作流、Prompt、工具调用和知识库分工清楚。
- [ ] 至少完成 3 次真实用户试用并记录问题。
- [ ] 发布前检查隐私、数据脱敏、版权和第三方服务限制。
