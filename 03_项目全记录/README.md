# 星火杯大模型应用创新赛

本项目记录 2026 星火杯大模型应用创新赛从报名、组队、选题、开发、发布、提交、推广到赛后复盘的全过程。本页是项目唯一首页。

## 当前状态

2026-07-30，已确认由两人共同推进“财富自由指南灯”，采用证据型大额消费决策智能体方向。讯飞星辰 Agent 平台中的指令型智能体草稿和三项首轮测试已经完成，Bot ID 为 5766257，当前保持未发布。

项目负责人已经完成 v0.2 财务基线和 v0.3 产品设计。v0.3 新增需求证据、替代证据、独立决策状态和复盘闭环。平台能力核对、八个责任单元搭建、新版测试、赛事官网报名和智能体发布仍待实际完成。

## 赛事目标

在 2026-08-13 24:00 前完成一款基于讯飞星辰 Agent 平台的智能体发布，并由队长提交初赛作品信息。目标场景需服务大学生学习、生活或就业中的一个真实痛点。

## 当前风险

赛事官网说明会动态调整，提交前需再次核对官网和官方交流群公告。

报名截止后队伍信息不能变更，因此队长、成员和分工应在报名截止前确认。

初赛需要同时完成智能体发布和作品信息提交，缺少任一项都会失去百强入围资格。

工作流新版必须使用 v0.2 公式。旧版指令型 Demo 的计算结果只作为历史测试证据，不直接用于新版验收。
