# 星火杯大模型应用创新赛

## 当前状态

2026-08-03，“财富自由指南灯”v0.3 基础工作流 Demo 已在讯飞星辰 Agent 平台完成搭建。工作流编辑页编号为 `661065`，实际节点为开始、信息采集、确定性决策核心、结果输出和结束。旧指令型智能体 Bot ID `5766257` 继续作为历史基线保留。

v0.3 保留 v0.2 确定性财务公式，并新增需求证据、替代证据、独立决策状态和复盘闭环。完整输入、缺失输入、财务红灯、安全边界和证据已齐五类平台用例通过，本地公式校验为 `ALL_PASS 6`。官方渠道发布版本已经创建；公开体验是否生效仍待平台审核。赛事官网报名和初赛作品信息提交仍待实际完成。

## 当前风险

赛事官网说明会动态调整，提交前需再次核对官网和官方交流群公告。

报名截止后队伍信息不能变更，因此队长、成员和分工应在报名截止前确认。

初赛需要同时完成智能体发布和作品信息提交，缺少任一项都会失去百强入围资格。

工作流新版必须使用 v0.2 公式。旧版指令型 Demo 的计算结果只作为历史测试证据，不直接用于新版验收。
