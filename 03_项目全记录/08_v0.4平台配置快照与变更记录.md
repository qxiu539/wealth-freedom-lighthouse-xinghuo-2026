必须输出一个合法 JSON 对象，不要输出 Markdown、代码围栏或解释。字段固定如下：
{
  "purchase_name":"",
  "price":"",
  "available_cash":"",
  "avg_daily_expense":"",

  "blocked_task":"",

  "alternative_price":"",

规则：
1. price、available_cash、avg_daily_expense、tracking_days、alternative_price 只写数字字符串。缺失填空字符串。
2. 七千、三万等含义明确的金额可规范为 7000、30000。四个月左右、半年等时间不能转换为精确记账天数，tracking_days 填空字符串。
3. impact_frequency 和 expected_usage_frequency 只允许 daily、weekly、occasional、unknown。用户明确说每天、每周、偶尔时，分别规范为 daily、weekly、occasional；没有频率信息时填 unknown。是否影响具体任务与频率是两个独立字段。
4. alternative_type 只允许 keep_using、repair、used、previous_generation、lower_budget、other 或空字符串。
5. 用户要求贷款保证时 safety_flags 包含 loan_guarantee；要求收益预测时包含 return_prediction；要求伪造收入或账本时包含 fabricate_data；主动提供银行卡、密码、验证码、身份证、精确住址或完整账本时包含 sensitive_data。多个值用英文逗号分隔。
6. 不推测真实需求强度、未来收入、商品质量、替代价格或未提供的事实。
7. 只有用户明确断定没有可行替代方案并给出具体原因时，才填写 no_alternative_reason。
8. 还没查、不知道、没比较、未评估、打算以后再看，都表示替代证据缺失。此时 no_alternative_reason 必须为空；仅在否定语境中提到维修、二手、上一代等类别时，也不要把它们写入 alternative_name 或 alternative_type。

## 当前确定性决策核心

核心节点输入 `input` 引用 `信息采集 / extraction_json`。平台代码编辑器共读取到 291 行，逐行编号连续，没有缺号。实际代码如下：

```python
# -*- coding: utf-8 -*-
import json
import math
from datetime import datetime

REQUIRED_ORDER = [
    ("available_cash", "可支配现金"),
    ("avg_daily_expense", "日均支出"),
    ("tracking_days", "记账天数"),
    ("price", "商品价格"),
    ("purchase_name", "商品名称"),
]

def text_value(data, key):
    value = data.get(key, "")
    return str(value).strip() if value is not None else ""

def number_value(data, key):
    raw = text_value(data, key)
    if raw == "":
        return None
    try:
        value = float(raw)
        if not math.isfinite(value):
            return None
        return value
    except Exception:
        return None

def round_half_up(value, digits=1):
    factor = 10 ** digits
    return math.floor(value * factor + 0.5) / factor

def json_result(payload):
    return {
        "decision_json": json.dumps(payload, ensure_ascii=False, separators=(",", ":")),
        "key1": [],
        "key2": {"key21": ""}
    }

def parse_input(raw):
    if isinstance(raw, dict):
        return raw
    value = "" if raw is None else str(raw).strip()
    fence = chr(96) * 3
    if value.startswith(fence):
        lines = value.splitlines()
        lines = lines[1:] if lines else lines
        if lines and lines[-1].strip().startswith(fence):
            lines = lines[:-1]
        value = chr(10).join(lines).strip()
    parsed = json.loads(value)
    if not isinstance(parsed, dict):
        raise ValueError("提取结果不是对象")
    return parsed

def financial_result(price, cash, daily, days):
    before_days = cash / daily
    remaining_cash = cash - price
    price_cash_ratio = price / cash
    direct_days = price / daily
    funds_sufficient = price <= cash
    after_days = remaining_cash / daily if funds_sufficient else None
    change_days = before_days - after_days if funds_sufficient else None
    if (not funds_sufficient) or (after_days is not None and after_days < 30) or price_cash_ratio >= 0.5:
        lamp = "red"
    elif (after_days is not None and after_days < 90) or price_cash_ratio >= 0.2 or days < 30:
        lamp = "yellow"
    else:
        lamp = "green"
    if days < 30:
        confidence = "low"
    elif days < 100:
        confidence = "medium"
    else:
        confidence = "high"
    return {
        "funds_sufficient": funds_sufficient,
        "direct_freedom_days": round_half_up(direct_days),
        "before_purchase_days": round_half_up(before_days),
        "remaining_cash": round_half_up(remaining_cash, 2),
        "after_purchase_days": None if after_days is None else round_half_up(after_days),
        "freedom_days_change": None if change_days is None else round_half_up(change_days),
        "price_cash_ratio": round_half_up(price_cash_ratio, 3),
        "financial_lamp": lamp,
        "sample_confidence": confidence
    }

def evidence_frequency(value, context):
    raw = str(value or "").strip()
    if raw in ("daily", "weekly", "occasional"):
        return raw
    source = "{} {}".format(raw, str(context or "").strip())
    keyword_groups = (
        ("occasional", ("偶尔", "偶发")),
        ("weekly", ("每周", "每星期")),
        ("daily", ("每天", "每日", "天天")),
    )
    negations = ("不", "非", "并非", "没有", "未")
    for normalized, keywords in keyword_groups:
        for keyword in keywords:
            position = source.find(keyword)
            if position < 0:
                continue
            prefix = source[max(0, position - 3):position]
            if any(mark in prefix for mark in negations):
                continue
            return normalized
    return "unknown"

def demand_evidence(data):
    impact_frequency = evidence_frequency(
        text_value(data, "impact_frequency"),
        text_value(data, "current_problem")
    )
    expected_usage_frequency = evidence_frequency(
        text_value(data, "expected_usage_frequency"),
        ""
    )
    checks = {
        "concrete_problem": bool(text_value(data, "current_problem")),
        "frequency_or_blocked_task": (
            impact_frequency in ("daily", "weekly", "occasional")
            or bool(text_value(data, "blocked_task"))
        ),
        "deadline_or_expected_usage": (
            bool(text_value(data, "purchase_deadline"))
            or expected_usage_frequency in ("daily", "weekly", "occasional")
        ),
        "current_solution": bool(text_value(data, "current_solution"))
    }
    labels = {
        "concrete_problem": "具体问题",
        "frequency_or_blocked_task": "问题频率或受阻任务",
        "deadline_or_expected_usage": "截止时间或预计使用频率",
        "current_solution": "当前解决办法"
    }
    count = sum(1 for value in checks.values() if value)
    status = "sufficient" if count == 4 else ("partial" if count >= 2 else "missing")
    return {
        "status": status,
        "satisfied_count": count,
        "checks": checks,
        "missing_items": [labels[key] for key, value in checks.items() if not value]
    }

def alternative_evidence(data, cash, daily, days):
    name = text_value(data, "alternative_name")
    no_reason = text_value(data, "no_alternative_reason")
    alt_price = number_value(data, "alternative_price")
    if alt_price is not None and alt_price > 0:
        status = "assessed"
    elif no_reason:
        status = "assessed"
    elif name:
        status = "partial"
    else:
        status = "missing"
    result = {
        "status": status,
        "name": name,
        "type": text_value(data, "alternative_type"),
        "price": alt_price,
        "no_viable_alternative_reason": no_reason,
        "financial_result": None
    }
    if alt_price is not None and alt_price > 0:
        result["financial_result"] = financial_result(alt_price, cash, daily, days)
    return result

def build_action(flow_mode, financial, demand, alternative, safety_flags, followups):
    if flow_mode == "safety_boundary":
        if "sensitive_data" in safety_flags:
            return "删除或打码敏感信息，只提供完成分析所需的汇总数字"
        return "补充真实汇总数据，并改用预算与替代方案比较"
    if flow_mode in ("need_input", "invalid_input"):
        return followups[0] if followups else "补充缺失信息后重新分析"
    if financial["financial_lamp"] == "red" or not financial["funds_sufficient"]:
        if not financial["funds_sufficient"] or alternative["status"] == "assessed":
            return "确定当前可承受的预算上限"
        return "记录一个当前资金范围内的替代方案及价格"
    if demand["status"] != "sufficient":
        return "连续7天记录问题出现次数和受影响任务"
    if alternative["status"] != "assessed":
        return "记录一个可行替代方案及价格"
    return "设置24小时等待期后再确认购买必要性"

def main(input):
    try:
        data = parse_input(input)
    except Exception as exc:
        payload = {
            "version": "v0.3",
            "flow_mode": "invalid_input",
            "error_node": "information_extraction",
            "error": str(exc),
            "followup_questions": ["请重新描述商品、价格、可支配现金、日均支出和记账天数"],
            "single_action": "请重新描述商品、价格、可支配现金、日均支出和记账天数"
        }
        return json_result(payload)

    flags = [item.strip() for item in text_value(data, "safety_flags").split(",") if item.strip()]
    if flags:
        messages = {
            "loan_guarantee": "不能承诺贷款一定通过或建议隐瞒负债",
            "return_prediction": "不能保证投资回报或未来收入",
            "fabricate_data": "不能伪造收入、支出或账本",
            "sensitive_data": "请删除银行卡、密码、验证码、身份证、精确住址和完整账本"
        }
        payload = {
            "version": "v0.3",
            "flow_mode": "safety_boundary",
            "safety_flags": flags,
            "safety_messages": [messages.get(flag, "该请求超出安全分析范围") for flag in flags],
            "financial_lamp": None,
            "decision_state": None,
            "single_action": build_action("safety_boundary", None, None, None, flags, [])
        }
        return json_result(payload)

    missing = []
    invalid = []
    for key, label in REQUIRED_ORDER:
        raw = text_value(data, key)
        if raw == "":
            missing.append(label)
            continue
        if key != "purchase_name":
            value = number_value(data, key)
            if value is None or value <= 0:
                invalid.append(label)
            elif key == "tracking_days" and not value.is_integer():
                invalid.append(label)

    if missing or invalid:
        flow_mode = "need_input" if missing else "invalid_input"
        followups = []
        for label in missing[:3]:
            followups.append("请补充" + label)
        for label in invalid[:max(0, 3 - len(followups))]:
            followups.append("请把" + label + "改为大于0的有效数字")
        payload = {
            "version": "v0.3",
            "flow_mode": flow_mode,
            "missing_fields": missing,
            "invalid_fields": invalid,
            "followup_questions": followups,
            "financial_lamp": None,
            "decision_state": None,
            "single_action": build_action(flow_mode, None, None, None, [], followups)
        }
        return json_result(payload)

    purchase_name = text_value(data, "purchase_name")
    price = number_value(data, "price")
    cash = number_value(data, "available_cash")
    daily = number_value(data, "avg_daily_expense")
    days = number_value(data, "tracking_days")

    financial = financial_result(price, cash, daily, days)
    demand = demand_evidence(data)
    alternative = alternative_evidence(data, cash, daily, days)

    if financial["financial_lamp"] == "red" or not financial["funds_sufficient"]:
        decision_state = "lower_budget_or_alternative"
    elif demand["status"] == "sufficient" and alternative["status"] == "assessed":
        decision_state = "ready_to_consider"
    else:
        decision_state = "gather_evidence"

    single_action = build_action("normal", financial, demand, alternative, [], [])
    now = datetime.now()
    payload = {
        "version": "v0.3",
        "flow_mode": "normal",
        "decision_id": "WFL-" + now.strftime("%Y%m%d%H%M%S"),
        "decision_date": now.strftime("%Y-%m-%d"),
        "purchase": {"name": purchase_name, "price": price},
        "financial": financial,
        "demand_evidence": demand,
        "alternative_evidence": alternative,
        "decision_state": decision_state,
        "single_action": single_action,
        "review": {
            "status": "pending",
            "review_fields": ["actual_purchase", "actual_price", "usage_frequency", "problem_improvement", "regret_level"]
        },
        "evidence_boundary": "仅基于用户明确提供的信息，不预测未来收入、收益或商品质量"
    }
    return json_result(payload)

```

你是财富自由指南灯 v0.3 的结果表达节点。输入是确定性代码生成的 JSON 字符串。你的职责是把已有结果转换成清晰中文，禁止重新计算、修改字段、补写事实或给出收益保证。


必须按 flow_mode 处理：
1. safety_boundary：只说明 safety_messages 和 single_action，不展示财务灯号、自由天数或购买结论。
2. need_input 或 invalid_input：只说明需要补充或修正的内容，最多列出 followup_questions 中已有的三项，并给出 single_action。不要生成不存在的财务结果。
3. normal：按以下顺序输出，内容简洁：

   五、下一步：只输出 single_action 这一项。
   六、复盘卡：展示 decision_id、decision_date 和 review.status。
