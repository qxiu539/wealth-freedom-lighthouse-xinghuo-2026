# 财富自由指南灯 Demo 实施日志与后续计划

## 2026-07-17

用户授权在讯飞星辰 Agent 平台制作 Demo，并说明后续不再关注电脑，要求日志和计划直接写入 Obsidian。

已完成设计收口。首版选择指令型智能体，原因是可以在较短时间内形成可测试的消费前决策闭环。工作流、本地账本接口、人生方格网页和真实财务数据同步暂不进入首版。

平台创建、配置、测试和保存结果继续追加到本页。

### 平台创建结果

已在讯飞星辰 Agent 平台创建指令型智能体“财富自由指南灯”。分类为生活，模型为星火大模型 Spark V4.0 Ultra，Bot ID 为 5766257。

已用完整配置替换平台自动生成的 345 字提示词。最终提示词包含五项最低输入、六条计算规则、样本不足提示、三种方案比较、灯号建议、单一行动项和贷款与伪造数据边界。

配置入口：<https://agent.xfyun.cn/agentbuilder/space/config/base?botId=5766257>

### 测试结果

完整输入测试通过。6999 元手机案例得到 87 天直接成本、375 天购买前覆盖、168 天购买后覆盖和约 207 天变化，输出三种方案、黄灯和一个行动项。

缺失输入测试通过。智能体只追问可支配资金、平均日花销和记账天数三个关键问题。

风险输入测试通过。智能体拒绝贷款保证和编造收入，转为预算与替代方案分析。

测试记录已写入 [[06_Demo测试记录]]。调试历史已清空，便于后续继续演示。

### 当前边界

智能体保持未发布。草稿、提示词和测试已保存。公开发布会改变分享权限，等待用户醒来后确认。

首版没有上传逐字稿、账本、个人财务数据或其他私密文件。所有测试均使用虚构演示数据。

## 后续计划

第一优先级是完成平台草稿和三个测试。

第二优先级是根据测试结果修正提示词，保留计算公式、输入边界、三种选择和单一行动项。

第三优先级是判断是否升级为工作流，把公式计算从大模型推理中拆出，降低算错风险。

第四优先级是研究如何让本地财富自由指南灯只上传必要的匿名汇总数据，不上传完整账本。

第五优先级是完成 3 位大学生访谈，验证自由天数反馈是否有帮助、是否制造压力，以及用户是否愿意连续记录。
