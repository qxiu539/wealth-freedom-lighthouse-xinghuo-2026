# 公式与灯号规则

版本：v0.2

本文件是工作流计算口径和灯号判断的唯一依据。平台配置、提示词和测试预期出现冲突时，以本文件为准。

## 处理优先级

工作流依次执行安全边界、必填检查、输入校验、资金校验、确定性计算、风险判断、方案生成和结果输出。

安全边界或输入校验未通过时，不进入普通灯号计算。

## 确定性公式

直接成本自由天数：

```text
direct_cost_days_raw = price / avg_daily_expense
```

购买前资金覆盖天数：

```text
coverage_before_days_raw = available_cash / avg_daily_expense
```

购买后剩余资金：

```text
remaining_cash = available_cash - price
```

购买后资金覆盖天数：

```text
coverage_after_days_raw = remaining_cash / avg_daily_expense
```

覆盖天数变化：

```text
coverage_change_days_raw = coverage_before_days_raw - coverage_after_days_raw
```

计划价格占可支配资金比例：

```text
price_cash_ratio_raw = price / available_cash
```

替代方案存在价格时，使用相同公式计算替代方案结果。替代方案缺少价格时，不生成虚构数字。

## 四舍五入

自由天数和覆盖天数在计算节点保留原始小数，展示时使用四舍五入后的整数。

资金金额展示到元。比例展示为百分比并保留 1 位小数。

所有条件判断使用未四舍五入的原始值，避免临界值因展示取整而改变分支。

## 样本可信度

| 记账天数 | `sample_confidence` | 输出要求 |
|---:|---|---|
| 少于 30 天 | `low` | 明确提示样本过短，灯号最高为黄灯 |
| 30 至 99 天 | `medium` | 提示单笔大额消费可能影响日均值 |
| 100 天及以上 | `high` | 按普通规则输出 |

## 灯号规则

先判断红灯，再判断黄灯，其余为绿灯。

出现以下任一条件时为红灯：

```text
price > available_cash
coverage_after_days_raw < 30
price_cash_ratio_raw >= 0.50
```

未触发红灯，出现以下任一条件时为黄灯：

```text
coverage_after_days_raw < 90
price_cash_ratio_raw >= 0.20
tracking_days < 30
```

未触发红灯或黄灯时为绿灯。

灯号只表示当前输入下的现金安全垫影响，不表示商品质量、个人价值或最终购买结论。

## 资金不足分支

当 `price > available_cash` 时：

```text
remaining_cash = available_cash - price
coverage_after_days_raw = null
coverage_change_days_raw = null
lamp = red
```

输出必须说明现有可支配资金不足，不鼓励贷款，不计算虚假的购买后覆盖天数。允许继续比较延后购买和更低预算替代方案。

## 安全边界分支

用户要求贷款保证、投资收益预测、伪造收入或账本数据时，设置：

```text
flow_mode = safety_boundary
```

该分支拒绝保证和伪造，转为提供预算比较、等待期或需要补充的真实信息清单。不得承诺用户会实现财富自由。

## v0.1 到 v0.2 的口径修正

旧版指令型 Demo 使用以下口径：

```text
post_avg_daily_expense = (avg_daily_expense * tracking_days + price) / tracking_days
coverage_after = (available_cash - price) / post_avg_daily_expense
```

该口径同时从资金中扣除价格并把价格加入日均花销，导致计划价格对覆盖天数产生两次影响。

v0.2 只从可支配资金中扣除一次价格，并继续使用原平均日花销计算购买后覆盖天数。旧版测试记录继续作为指令型草稿的历史证据，工作流新版必须按 v0.2 重新测试。

## 示例

输入为价格 6999 元、可支配资金 30000 元、平均日花销 80 元、记账 120 天时：

```text
direct_cost_days = 6999 / 80 = 87.49，展示 87 天
coverage_before = 30000 / 80 = 375 天
remaining_cash = 30000 - 6999 = 23001 元
coverage_after = 23001 / 80 = 287.51，展示 288 天
coverage_change = 87.49，展示 87 天
price_cash_ratio = 6999 / 30000 = 23.3%
```

计划价格占可支配资金比例超过 20%，结果为黄灯。
