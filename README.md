## 协作方式

开始工作前运行 `git pull` 获取最新版本。

每次只提交一个明确任务，提交说明写清完成内容，例如 `补充输入校验节点设计`、`记录完整输入测试结果`。

平台配置发生变化时，同步更新配置记录和测试日志。产品规则发生变化时，同步更新工作流方案和参赛材料。

提交前检查是否包含手机号、账号密码、验证码、身份证号、真实账本、银行卡信息或未经授权公开的原始材料。此类内容不得进入仓库。
