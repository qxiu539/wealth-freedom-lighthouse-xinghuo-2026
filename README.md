本仓库用于 2026 届科大讯飞星火杯大模型应用创新赛团队协作，集中保存项目分工、工作流设计、参赛材料、Demo 配置、测试记录和来源材料。

本仓库为公开协作仓库，仅保留适合公开的项目资料。含个人信息的参赛填写稿和完整逐字稿保存在团队内部，不进入公开仓库。

## 当前分工

队长担任项目负责人，主责项目统筹、产品设计、工作流架构、验收和参赛材料。

队员担任工作流负责人，主责工作流搭建、平台调试、测试和演示。

两人共同完成目标用户试用、演示彩排和最终材料核对。

## 协作方式

开始工作前运行 `git pull` 获取最新版本。

每次只提交一个明确任务，提交说明写清完成内容，例如 `补充输入校验节点设计`、`记录完整输入测试结果`。

平台配置发生变化时，同步更新配置记录和测试日志。产品规则发生变化时，同步更新工作流方案和参赛材料。

提交前检查是否包含手机号、账号密码、验证码、身份证号、真实账本、银行卡信息或未经授权公开的原始材料。此类内容不得进入仓库。
